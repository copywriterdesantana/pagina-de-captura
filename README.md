# Página de captura · skill grátis para o Claude

Escreve a copy completa da sua página de captura a partir de quatro respostas: qual é a isca, qual é a dor do seu público, o que ele deseja e o que a isca promete.

Você recebe oito blocos prontos para colar no seu construtor de páginas:

| Bloco | Para que serve |
|---|---|
| Headline | Fazer a pessoa certa parar |
| Subheadline | Dizer o que ela ganha e como |
| Benefícios | Mostrar o que tem dentro da isca |
| Texto do botão | Verbo + o que ela recebe |
| Microcopy | Tirar o último medo antes do clique |
| Versão curta | Pop-up, barra ou bio |
| Versão longa | A página inteira em texto corrido |
| Prova | Só com fatos reais que você informar |

Duas coisas que ela faz diferente:
- **Não inventa prova.** Depoimento, número de alunos ou resultado que você não informou vira um marcador como `[DEPOIMENTO REAL AQUI]` para você preencher.
- **Revisa antes de entregar.** Passa a página por um checklist contra texto com cara de IA e contra frase genérica que serviria para qualquer nicho.

Veja um exemplo completo em [`exemplos/`](exemplos/).

## Instalação

**No Claude Code**

Baixe este repositório e copie a pasta para a pasta de skills do Claude com o nome `pagina-de-captura`:

- Windows: `%USERPROFILE%\.claude\skills\pagina-de-captura`
- Mac e Linux: `~/.claude/skills/pagina-de-captura`

Abra uma conversa nova e ela já está disponível.

**No claude.ai**

Compacte a pasta num arquivo `.zip` e envie na área de Skills das configurações.

**Em outras IAs**

Cole o conteúdo do `SKILL.md` e dos arquivos de `references/` como instrução da conversa ou do projeto.

## Como usar

Peça do jeito que você falaria:

- "Faz a página de captura do meu ebook de receitas"
- "Preciso de uma landing page para a minha aula grátis de sábado"
- "Revisa essa página de captura" (e cole a página)

Se faltar alguma informação, ela pergunta tudo de uma vez.

## O que ela não faz

Ela escreve a copy. Não monta o visual da página, não cria o formulário, não publica e não guarda as versões que você já gerou.

## Versão completa

A skill escreve a copy quando você pede. A versão completa é um app de página de captura feito para o seu negócio: com a sua voz, as suas iscas e as suas regras já guardadas, para você e a sua equipe gerarem cada nova página no navegador, sem instalar nada e sem repetir o briefing toda vez.
